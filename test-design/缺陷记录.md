## 三、缺陷详情

### DEF-2026-001　未勾选《用户协议》仍可完成登录

| 字段 | 内容 |
|---|---|
| **所属模块** | 登录 · 协议校验 |
| **发现方式** | 执行用例 TC-C01（未勾选协议点登录） |
| **违反规格** | R-2.5 |
| **环境** | Windows 11 · Edge · 本地页面 |
| **复现概率** | 10/10（必现） |
| **前置条件** | 已进入密码页，手机号与密码为有效账号 |

**复现步骤**

1. 手机号输入 `13800138000`，点击「下一步」。
2. 密码输入 `abc123`。
3. 不勾选页面底部《用户协议》与《隐私政策》。
4. 点击「登录」。
5. 观察页面跳转。

**预期结果**：应被拦截，提示「请先阅读并同意用户协议」，停留在密码页。

**实际结果**：直接进入「登录成功」页，全程无协议相关提示；代码中未读取协议勾选状态。

**影响范围**

- 受影响用户：全部登录用户。
- 影响功能：登录流程、协议同意链路。
- 数据影响：系统不保存任何同意记录，无法证明用户已同意条款。
- 风险：违反个人信息处理「告知—同意」要求，存在合规与审核风险。

**严重程度**：S2。不阻塞登录，但构成合规缺口，无法举证。
**优先级**：P1。合规问题通常为版本上线阻断项。

**定位建议**：登录点击处理未读取复选框状态，仅校验密码非空与长度；页面无对应提示分支。

**修复建议**

1. 点击登录时先校验协议勾选，未勾选则提示并中止。
2. 登录成功后将协议版本与同意时间随账号信息记录。
3. 协议版本更新时重新征得同意。

**验证标准**

- 未勾选点击登录：出现提示，停留密码页，不进入成功页。
- 勾选后登录：正常进入成功页。
- 协议版本升级后：强制重新确认。

**状态**：已关闭。2026-11-14 修复并验证通过。

### DEF-2026-002　同一手机号连续登录失败无锁定

| 字段 | 内容 |
|---|---|
| **所属模块** | 登录 · 失败处理 |
| **发现方式** | 执行用例 TC-C06（连续失败 6 次） |
| **违反规格** | R-3.1 |
| **环境** | Windows 11 · Edge · 本地页面 |
| **复现概率** | 10/10（必现） |
| **前置条件** | 已进入密码页，使用已注册手机号 |

**复现步骤**

1. 手机号输入 `13800138000`，点击「下一步」。
2. 密码输入错误值（如 `wrong123`），点击「登录」。
3. 重复步骤 2 共 6 次。
4. 观察每次提示文案与是否限制继续尝试。

**预期结果**：第 5 次失败后锁定 60 秒，第 6 次提示「尝试过于频繁，请稍后再试」，锁定期间不校验密码。

**实际结果**：6 次均返回「账号或密码错误」，无锁定提示、无倒计时，可无限次继续尝试。

**影响范围**

- 受影响用户：全部登录用户。
- 影响功能：登录失败处理、账号安全。
- 风险：单号码可无限次尝试，弱密码账号面临撞库风险；无频率约束时攻击成本极低。

**严重程度**：S2。不直接影响可用性，但缺失账号安全基线。
**优先级**：P1。撞库为高频攻击方式，属必须修复项。

**定位建议**：登录处理无失败计数与锁定状态，每次提交独立校验，未维护 `failCount` 与 `lockUntil`。

**修复建议**

1. 按手机号维护失败计数，连续失败 5 次写入锁定截止时间（当前 + 60 秒）。
2. 锁定期间直接返回提示，不进入密码校验。
3. 登录成功后清零计数。
4. 计数与锁定时长抽为配置。

**验证标准**

- 连续失败 5 次后：第 6 次出现锁定提示，正确密码也无法登录。
- 等待 60 秒后：可正常登录，计数清零。
- 登录成功后：再次失败从 1 开始计数。

**状态**：已关闭。2026-11-14 修复并验证通过。

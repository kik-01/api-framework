# 登录模块 · 测试用例设计文档

> **设计方法**：等价类划分 + 边界值分析 + 场景法 + 判定表
> **作者**：陈贵方　**时间**：2026.05 — 2026.06
> **规模**：56 条用例，七组，P0 18 / P1 22 / P2 16

## 一、被测对象与覆盖范围

**交互参照**：微信 App 登录页（Android 最新正式版）。两步式流程、手机号输入过滤空格与字母、手机号页按钮置灰、密码页点击后才提示、失败提示统一为「账号或密码错误」——均以其实际交互为准。

**执行环境**：自建测试靶场 `target/login-demo.html`（单页应用，配套 `需求规格.md`）。

**靶场说明**：微信 App 仅作交互参照，不可修改、无法提交与验证缺陷；靶场 `target/login-demo.html` 按同样交互实现，用于走完「执行 → 发现 → 修复 → 复验」闭环。

**进入方式**：浏览器打开 `target/login-demo.html`

**页面元素**：

| 元素 | 说明 |
|---|---|
| 手机号输入框 | 输入 11 位中国大陆手机号 |
| 密码输入框 | 6-20 位，支持字母/数字/符号 |
| 「登录」按钮 | 提交登录 |
| 「用短信验证码登录」 | 切换到验证码登录方式 |
| 「更多选项」 | 展开：切换账号、找回密码 |
| 「同意《用户协议》和《隐私政策》」 | 勾选框（未勾选不能登录） |

---

| TC-D08 | 切换登录方式后数据保留 | 已填手机号 | 切到验证码登录再切回密码登录 | 手机号保留，密码按产品定义是否清空 | P2 |
